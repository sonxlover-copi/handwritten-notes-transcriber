# Проверка качества расшифровки

Качество распознавания нельзя оценить только тем, что приложение вернуло текст. Для сравнения моделей подготовьте собственный небольшой набор страниц:

1. Возьмите 10–20 страниц с разными почерками и качеством фотографий.
2. Для каждой страницы вручную подготовьте точную эталонную расшифровку.
3. Прогоните страницы через модель и сохраните результат.
4. Сравните тексты по Character Error Rate (CER): чем значение ближе к 0, тем меньше ошибок на уровне символов.
5. Отдельно проверьте формулы, числа и имена: небольшая символьная ошибка там может менять смысл.

Не включайте личные страницы или тексты без разрешения владельца в публичный GitHub. Локальный набор можно хранить в `evaluation/private/`, эта папка добавлена в `.gitignore`.

# Документация Local RAG Assistant

## Добавление документов

Сервис индексирует файлы Markdown (`.md`) и обычного текста (`.txt`) из каталога `data/docs/`. После добавления или обновления файлов запустите `docker compose run --rm api python -m app.ingest`. Скрипт делит документ на фрагменты размером до 800 символов с перекрытием 120 символов и сохраняет embeddings в Chroma.

Повторный запуск обновляет фрагменты изменённого источника. Индекс хранится в Docker volume `chroma_data`, поэтому он переживает пересоздание API-контейнера.

## Вопросы к базе знаний

Отправьте `POST /ask` с JSON-полями `question` и необязательным `top_k`. Поиск выбирает наиболее похожие чанки. Если их relevance score меньше `MIN_RELEVANCE`, API возвращает сообщение о нехватке данных и не вызывает языковую модель.

Когда контекст найден, он передаётся локальной модели Ollama. В ответе API есть список `sources` с именем файла, оценкой релевантности и отрывком использованного текста.

## Модели

По умолчанию чат использует `qwen2.5:3b`, а модель `nomic-embed-text` строит векторы документов и запросов. Модели загружаются в контейнер Ollama и доступны через внутренний адрес `http://ollama:11434`.

## Типовой запуск

1. Запустить контейнер Ollama.
2. Скачать chat-модель и embedding-модель командой `ollama pull`.
3. Запустить FastAPI через Docker Compose.
4. Запустить индексацию документов.
5. Проверить `/health`, затем отправить вопрос в `/ask`.
